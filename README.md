# TK Čelákovice — návrhy nového webu

**Náhled:** https://petrluxa.github.io/Celakovice/

Dva návrhy úvodní stránky nového webu tkcelakovice.cz. Obsah je stejný, liší se náladou a hlavním nápadem:

- **01 Grafit** — tmavá moderní, časová osa rekonstrukce dvorců v roce 2025
- **02 Století** — světlá klasická, sto let klubu na jedné ose (1930 → 2030)

Texty, ceny a fotky pocházejí ze současného webu klubu a webu Tenisové akademie Čelákovice.
Dronové fotografie: David Holub.
